# Konzepte

Platz für Hintergrundwissen, das über einzelne Befehle hinausgeht – z. B.:

- Networking (Services, Ingress, CNI, NetworkPolicies)
- Storage (PV/PVC, StorageClasses, CSI)
- RBAC (Roles, ClusterRoles, ServiceAccounts)
- Scheduling (Taints/Tolerations, Affinity, Requests/Limits)

!!! tip
    Pro Thema eine Seite anlegen und in `mkdocs.yml` unter `Konzepte` eintragen.
